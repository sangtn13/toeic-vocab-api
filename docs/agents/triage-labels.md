# Triage Labels

Use this canonical label vocabulary:

| Role | Label |
| --- | --- |
| Maintainer needs to evaluate | `needs-triage` |
| Waiting on reporter/user info | `needs-info` |
| Fully specified and agent-ready | `ready-for-agent` |
| Needs human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |

Do not create duplicate labels with similar meanings unless the repository owner changes this mapping.
