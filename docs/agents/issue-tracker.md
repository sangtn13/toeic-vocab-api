# Issue Tracker

This repo uses GitHub Issues for durable work tracking.

- Repository: `https://github.com/sangtn13/toeic-vocab-api`
- Remote: `origin`
- Default workflow: create and update issues through the GitHub CLI when available.
- Offline fallback: write temporary planning notes under `docs/specs/` rather than inventing an issue format.

When turning a request into implementation work, prefer small vertical slices that include backend controller/service/DTO/test changes and frontend contract updates when needed.
